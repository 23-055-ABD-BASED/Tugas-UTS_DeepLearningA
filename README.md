**Analisis Pengaruh Transfer Learning, Augmentasi Data, dan Fine-Tuning pada Klasifikasi Penyakit Daun Cabai Menggunakan MobileNetV3-Small**

Cabai adalah komoditas hortikultura bernilai ekonomi tinggi yang sering terganggu penyakit daun seperti antraknosa, bercak daun Cercospora, dan leaf curl. Diagnosis visual di lapangan bergantung pada pengalaman dan rawan keliru karena gejala antar penyakit mirip, sehingga dapat menurunkan hasil panen. Deep learning (CNN) memungkinkan klasifikasi otomatis dari citra daun, dan transfer learning dengan model ringan seperti MobileNetV3-Small lebih efisien daripada melatih CNN dari awal. Namun, manfaat augmentasi dan fine-tuning belum tentu sama pada setiap dataset. Penelitian ini membandingkan empat skenario pelatihan (Custom CNN, MobileNetV3-Small baseline, dengan augmentasi, dan dengan fine-tuning) pada dataset penyakit daun cabai dari Bangladesh.
